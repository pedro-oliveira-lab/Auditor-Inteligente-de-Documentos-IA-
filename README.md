# Auditor-Inteligente-de-Documentos-IA-
Este projeto utiliza Inteligência Artificial Generativa para automatizar o processo de auditoria e conformidade (compliance) entre diferentes tipos de documentos. Através do modelo Gemini 1.5 Flash, o sistema realiza uma análise multimodal (texto e visão) para garantir a integridade das informações e reduzir riscos de fraudes.
